# 饿饿饭饭 · 余额桌宠 V3

一只端着碗的小家伙，蹲在桌面角落帮你盯着 **DeepSeek 账户余额**。
余额就是她的饭钱 —— 钱多她笑，钱少她饿，碗空了就该充值了。

```
        ┌──────────────────────────┐
        │ 饿饿饭饭 · 余额        ● │   ← 状态灯（刷新时会转圈）
        │ ¥128.66                  │   ← 主数字
        │ 赠金 ¥8.66 · 充值 ¥120.00│   ← 金额构成
        │ 12:30 更新 · 剩 4分55秒  │   ← 倒计时
        │ ▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░  │   ← 刷新进度条
        └────────────┬─────────────┘
                 （立绘：饿饿饭饭）
```

* **单击桌宠 = 立刻刷新余额**（本程序最核心的用法）
* 自动刷新只有三档：**每隔 1 分钟 / 每隔 5 分钟 / 每隔 10 分钟**（右键菜单里选）
* 纯 Python 标准库（tkinter + urllib + threading），**不需要 pip 装任何东西**
* 无边框 + 真透明背景 + 置顶，拖动即可换位置，位置自动记住
* 异步查询：刷新时不会卡住窗口，随手点随手有反馈

## 一、快速开始

1. 双击 **`启动桌宠.bat`**（想完全不闪黑窗就双击 **`启动桌宠.vbs`**）
2. 首次运行会弹出输入框，粘贴你的 DeepSeek API 密钥（`sk-` 开头），点「保存并刷新」
3. 完成。桌宠会出现在屏幕右下角，气泡里就是当前余额
4. 想以后一键启动：双击一次 **`创建桌面快捷方式.bat`**，桌面上会多出一个快捷方式

> 密钥去哪申请？菜单里点「去申请密钥」，或访问
> <https://platform.deepseek.com/api_keys>
>
> 只是想先看看它长什么样：`python balance_pet.py --demo`（演示模式，不联网、用假数据）。

## 二、操作说明

| 操作 | 效果 |
| --- | --- |
| **左键单击桌宠** | **立刻刷新余额**（倒计时重新开始） |

| 右键 | 打开菜单 |
| 双击 | 也是立刻刷新 |
| Esc | 退出桌宠 |

右键菜单（自己画的，不依赖系统菜单，所以样式跟气泡统一、也不会出现「点了没反应」）：

```
─────────────────────

```

点「桌宠大小」或「不透明度」会原地翻到下一页（最上面一行是 `← 返回`）：

```

 ○ 特大（150%）
 ○ 巨大（200%）
 ○ 超大（250%）
 ─────────────

```

菜单的收法：点空白处 / 点桌宠 / 点别的程序 / 按 Esc 都会收掉；再点一次右键也能开关。

**桌宠大小**：不只立绘变大，气泡、字号、进度条、留白一起等比缩放，所以任何一档都不会出现
「字挤破气泡」。实际用的是「屏幕缩放 × 你选的档位」，例如 125% 缩放的屏幕上选「标准 100%」，
渲染倍数就是 1.25，任何 DPI 下看起来都一样大。档位对应 `assets/pet_060.png` ～
`pet_300.png` 七张素材，切换时只是换图，不会把位图硬拉大，所以**放大也不会糊**。
缩放时左上角位置不变；要是调得比屏幕还高，会自动贴顶让气泡露出来。

**不透明度**：整只桌宠（气泡 + 立绘）一起变淡，方便在它挡视线时留着看数字。
设置会写进 `config.json`，下次启动照旧。单击、拖动、右键在淡到 40% 时一样好使。

气泡里的四行信息和状态灯会跟着余额变：

| 状态 | 颜色 | 表现 |
| --- | --- | --- |
| 充足 | 🟢 绿 | 显示金额，副行是「赠金 / 充值」构成 |
| 快见底 | 🟡 黄 | 金额变黄，副行提示「余额见底，快喂饭！」 |
| 碗空了 | 🔴 红 | 主行「碗空了…」 |
| 查不到 | 🔴 红 | 主行「查不到饭钱了」，副行给出原因（401 / 网络不通…） |
| 没密钥 | 🔵 蓝 | 主行「还没给我饭钱」，双击/右键可填密钥 |

## 三、命令行

```bat
python balance_pet.py                    正常启动
python balance_pet.py --demo             演示模式：假数据看外观，不联网
python balance_pet.py --check            自检：Python / tkinter / 立绘 / 配置 / 接口
python balance_pet.py --set-key sk-xxxx  保存密钥并顺手验证连通性
python balance_pet.py --interval 60      把自动刷新间隔改成 60 秒（只认 60/300/600/0）
python balance_pet.py --size 150         把桌宠大小改成 150%（认 60/80/100/125/150/200/250）
python balance_pet.py --opacity 80       把不透明度改成 80%（30 ~ 100）
```

不想看到黑窗，就用 `pythonw.exe balance_pet.py` 启动（两个 bat/vbs 已经这么干了）。

## 四、配置文件

配置存在同目录的 `config.json`（菜单 →「打开配置文件」可直接编辑）：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `api_key` | `""` | DeepSeek 密钥；环境变量 `DEEPSEEK_API_KEY` 优先级更高 |
| `base_url` | `https://api.deepseek.com` | 接口地址，可指向代理 |
| `interval_sec` | `300` | 自动刷新间隔，只认 `60` / `300` / `600`，`0` = 暂停 |
| `low_threshold` | `10.0` | 低于该金额进入「快见底」黄色状态 |
| `size_scale` | `1.0` | 桌宠大小，只认 `0.6` / `0.8` / `1.0` / `1.25` / `1.5` / `2.0` / `2.5`（写别的会吸附到最近一档） |
| `opacity` | `1.0` | 不透明度 `0.3` ~ `1.0`，可以随便写小数 |
| `always_on_top` | `true` | 是否总在最前 |
| `pos` | `null` | 上次窗口位置，自动写入 |

密钥只写在本机这个文件里，除了 `api.deepseek.com` 不会发往任何地方。

## 五、常见问题

**双击 bat 一闪而过 / 没反应**
先双击 `诊断.bat`，它会打印 Python 路径和自检结果并停住窗口等你看。
如果连窗口都没有，检查同目录是否生成了 `pet_error.log`，里面是完整崩溃堆栈。

**提示「No Python interpreter with tkinter was found」**
装一个 Python 3.9+ 并勾选 *Add python.exe to PATH*。启动脚本也会自动尝试
`%USERPROFILE%\.dsh\dsh-runtimes\...\python\python.exe`（装了 DSH 就能直接跑）。
注意：要的是带 `tkinter` 的解释器，某些精简版 Python 没有。

**气泡显示「密钥无效或已失效 (401)」**
密钥写错或已被删除。右键 →「设置密钥…」重填。

**气泡显示「网络不通」**
公司网络 / 代理拦了 HTTPS。可以把 `base_url` 改成你的代理地址。

**立绘没显示，出现一只简笔画小人**
`assets/` 里的素材丢了。用带 Pillow 的 Python 跑一次
`python build_assets.py`（默认从上一级目录的 `Segment_20260929_212949373.png` 重新生成）。

**右键菜单点不动 / 点了没反应**
V3 已经把右键菜单改成自己画的了（不再用系统菜单），这个毛病已经修掉。
如果你手上还是旧版，菜单会弹出来但点任何一项都只把菜单收掉 —— 换成本目录的
`balance_pet.py` 即可。【根因记录在代码注释里：老版本把鼠标事件同时绑在 canvas 和
顶层窗口上，一次点击会被处理两遍；另外系统菜单在无边框置顶窗口上不可靠。】

**桌宠边缘有一圈紫边**
已经修掉了（`assets/` 里的素材是修正后重新生成的）。成因：Tk 的 `-transparentcolor`
只认「颜色正好等于色键」的像素，而旧版 `build_assets.py` 是把带 alpha 的立绘**渐变混合**
到品红色键上的 —— 半透明边缘像素被品红染紫，既不是精确色键（抠不掉），也不是立绘颜色，
于是在屏幕上留成一圈紫边。现在改成**按 alpha 二值化**：够实（≥125/255）当不透明，
否则直接刷成精确色键，一个混合像素都不剩，紫边随之消失。
手上如果是旧的 `assets/`，用带 Pillow 的 Python 重跑一次 `build_assets.py` 就行。

**桌面太花，想让桌宠别挡路**
右键 →「桌宠大小」调小一点，或者「不透明度」调淡一点，也可以「隐藏 10 秒」。
窗口四周的透明区域是点击穿透的，只有立绘和气泡会接收鼠标。

**桌宠调得太大，跑到屏幕外面了**
不会。缩放时左上角位置保持不变，并且会自动把窗口拉回屏幕内；比屏幕还高时会贴顶显示，
气泡始终看得见。真嫌大就右键 →「桌宠大小」→「恢复默认大小」。

**有没有快捷键可以一键盘调大小？**
菜单里点两下就行。想用命令行或脚本改：
`python balance_pet.py --size 125` / `python balance_pet.py --opacity 70`。

**高分屏下会不会糊？**
不会。程序启动时会声明 DPI 感知，并按「屏幕缩放 × 桌宠大小」自动挑
`pet_060` / `pet_080` / `pet` / `pet_125` / `pet_150` / `pet_200` / `pet_250` / `pet_300`
里最清晰的一张，放大靠换素材而不是拉伸位图。

**余额多久刷新一次合适？**
官方接口没有严格限流，5 分钟足够；想更实时就在菜单里选 1 分钟。
注意「点一下立刻刷新」是手动的，不会因此把接口问爆 —— 同一时刻只会有一个请求在飞。

## 原理备注（想改代码的话）

* 透明靠 Tk 的 `-transparentcolor #ff00ff`，而这个机制**只认精确的颜色值**：
  所以色键版立绘不能有半点半透明混合，否则混到品红上的边缘像素会以紫边形式留在屏幕上
  （`on_key()` 因此按 alpha 二值化，cutoff=125 是按「实心像素总数对齐 alpha 覆盖率」选的）。
  品红区域同时也是鼠标穿透区。
* **鼠标事件只绑在 canvas 上**。canvas 铺满整窗，而 Tk 的 bindtags 是
  「控件 → 类 → 顶层窗口 → all」，给 root 也绑一份的话同一次点击会走两遍：
  右键会连开两次菜单（第二次立刻把第一次关掉，看起来就是「点了没反应」），
  单击也会连发两次刷新请求。
* 右键菜单是自己画的（`MenuPanel`）：一个无边框置顶小窗 + Canvas，点击走自己的绑定。
  Tk 原生菜单在这只桌宠窗口上不可靠（菜单是系统弹的独立窗口，点击要么被顶层窗口
  抢走、要么只把菜单收掉不执行命令）。菜单也不做 `grab_set`——局内抓取会把
  面板外面的点击吞掉，改用「桌宠自己收 + 每 50ms 轮询鼠标按键」来收菜单。
* `build_assets.py` 从图片四边灌水判断背景（而不是简单按亮度阈值），
  所以碗里的白、蕾丝的白不会被误伤；边缘还做了「白底反解」去掉白边。
* 查询跑在后台线程，结果通过 `queue` 交回主线程；Tk 只在主线程里被碰。
